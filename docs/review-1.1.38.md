# 开箱与 Mod Menu 复核 · 1.1.38

## 不一致的原因

1. 设置页编辑服务端具体皮肤权重和额外奖励；旧开箱页却独立从本地皮肤目录按箱子品质抽展示项。自定义跨品质池、绿苹果和职业卡没有被正确展示。
2. 旧预览固定凑满十张卡，并伪造“罕见特殊物品”；空池还使用普通 Minecraft 物品填充。
3. Mod Menu 首页固定展示第一个箱子的摘要，并将缺失的配置字段当成默认值，容易被误认成当前正在编辑的箱子。
4. 箱子选择列表直接显示部分翻译键；长名称没有恰当截断。

## 修改

- 服务端公开实际候选奖励，开箱预览和转盘使用同一目录；保存后的目录更新由现有广播同步。使用原有 catalog v3 JSON 的附加字段，不发送管理事务或个人数据。
- 旧自动品质池没有对应品质时保持空池，不再静默回退到全部品质。
- 预览按真实条目分页、支持鼠标滚轮及悬停完整名称；奖励类型和图标与设置页一致。
- 底部操作成组居中；确认弹窗由玩家主动打开。删除无效检视标签、装饰导航、重复的钥匙选择和首页重复刷新。
- 修复箱盖悬空和转盘开始时箱体位置跳变；保留原开盖、减速、暗场和揭晓节奏。
- 结果物品尺寸收敛，多奖励结果每页八项，避免溢出底栏。
- 箱子列表翻译、名称截断、空搜索提示和滚动指示；首页显示目录概览，离线不假装显示服务器启用状态。

## 验证

- Gradle build：通过；285 项自动测试，零失败、零错误。
- 真实 Minecraft 1.21.1 客户端：仓库点击箱子 → 开箱页 → 奖励翻页 → 打开确认 → 取消 → 重新确认 → 开盖转盘 → 揭晓 → 返回仓库。
- 开箱录帧：1280×720 / GUI 2，1920×1080 / GUI 4，854×480 / GUI 2；小窗口附加 12 项奖励前后翻页检查通过。
- 设置页：43 项检查通过，覆盖增删替换、实时概率、无效值阻止、草稿、服务端保存与磁盘重新加载、复制与重置、Tab 与 Esc。
- 设置页尺寸：854×480、1280×720、1920×1080；GUI 缩放 2、3、4、自动；中英文。
- Mod Menu factory、配置分类与箱子管理入口以及父页面返回经过客户端检查。
- 发布 JAR 不含 tools 下的测试代码或测试皮肤；build/libs 与临时目录副本 SHA-256 相同。

测试边界：客户端使用独立测试目录和测试皮肤；按钮调用真实生产页面的输入处理。开箱响应由录制装置注入，未连接真实多人服务器、未消费用户存档中的箱子。配置保存检查调用实际服务端配置服务并读取独立测试目录。权重、限额、个人去重仍由服务端结算；预览表示候选范围，不是个人最终中奖概率。
