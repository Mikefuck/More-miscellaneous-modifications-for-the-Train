# Mod Menu 按钮核对与修复（1.1.43）

## 范围与方法

从 `fabric.mod.json` 的 Mod Menu 入口追踪到 `ModMenuIntegration`、`LotteryConfigRootScreen`，再检查从管理页可进入的皮肤衣柜、箱子管理、箱子选择、外观预览和邮件编辑页面。逐类核对按钮回调、客户端请求、服务端处理与返回路径。

本次完成了源码核对、构建、自动测试与交付 JAR 核对，未启动真实游戏客户端，因此不将这些结果视为实际画面、键鼠操作或多人联机验证。

## 按钮作用核对

| 页面 | 按钮或操作 | 实际作用与结论 |
| --- | --- | --- |
| 管理入口 | 分类切换、返回 | 切换管理内容；返回传入的 Mod Menu 父页面。 |
| 玩家资产 | 刷新列表、新建备份 | 请求玩家快照；服务端将备份写入当前世界的 `lottery_backup`。 |
| 玩家资产 | 批量加、减、设定 | 服务端只处理当前在线玩家，已改名为“在线 +N / -N / =N”并增加范围提示。 |
| 玩家资产 | 选择玩家、基础资产/角色卡、窄屏返回列表 | 改变选中 UUID 或可见子页面；搜索没有匹配项时显示文字提示。 |
| 玩家资产 | 此人加、减、设为 | 请求修改选中玩家绿苹果，包含离线玩家；已增加严格整数校验和请求反馈。 |
| 角色卡 | 六类卡片的加、减、设定 | 请求服务端修改对应卡片数量，保留权限、损坏存储和请求等待锁；输入错误不会替换成默认值或截断小数。 |
| 称号 | 刷新、添加/删除模板、保存 | 请求快照或编辑模板草稿，保存提交到服务器；已修复最后一项无法删除、新 ID 重复及草稿被快照覆盖的问题。 |
| 称号 | 授予模板、自定义授予、收回、设佩戴 | 对选中玩家发送对应称号操作；自定义输入在页面重建后保留。 |
| 称号 | 卸下 | 发送 `set_current` 和空称号，只移除佩戴状态，保留拥有清单。原按钮错误发送 `clear`，会清空所有称号。 |
| 皮肤内容 | 打开皮肤衣柜 | 在线时服务端返回带打开标记的皮肤快照，客户端打开衣柜；离线时打开本地浏览页面。 |
| 皮肤衣柜 | 分类、搜索、筛选、排序、翻页、二维/三维 | 修改当前浏览或预览状态；分页边界正确禁用。 |
| 皮肤衣柜 | 穿戴/恢复、帽子显示、刷新、返回 | 穿戴提交到皮肤或称号协议；帽子显示保存本地设置；刷新请求目录；返回父页面。 |
| 开箱管理 | 分类、前后选择、箱子列表、新建、复制 | 修改所选箱子或草稿；箱子列表和外观预览均返回原管理页。 |
| 开箱管理 | 资料/外观枚举、外观预览 | 修改草稿字段；预览读取当前草稿外观。 |
| 奖励编辑 | 选择、编辑、添加、移除、更换皮肤、筛选、翻页、抽取规则 | 修改当前奖励或箱子草稿，统一走箱子保存验证和同步流程。 |
| 奖励编辑 | 只抽此奖励（100%） | 已同时清零其他权重与独立附加概率，启用固定奖池、固定为一次抽取，并按皮肤/物品选择调整皮肤数与保底数。产出配额仍会影响奖励可用性。 |
| 产出配额 | 周/月切换、翻页 | 修改各品质对应的配额周期，翻页查看五个品质；保存后才应用。 |
| 开箱管理 | 重置当前/冲突重载、保存、返回 | 重置或重载草稿；服务端校验保存；返回父页面。保存等待期间防止重复编辑。 |
| 邮件 | 内容/收件人/奖励/皮肤/箱子分类、范围、全选/清空、玩家选择 | 修改邮件草稿或目标选择。 |
| 邮件 | 阵营卡类型、箱子类型、箱子/钥匙 | 修改附件类型；数量和正文随页面切换保留。 |
| 邮件 | 发送邮件、返回 | 将草稿提交到服务端，经权限、频率和附件验证后发送；服务器最终结果仍通过聊天消息反馈，页面只表示“已提交”。 |
| 底部操作栏 | 刷新 | 玩家/称号页刷新相关快照；开箱页刷新开箱配置；皮肤和邮件页隐藏这个无关入口。 |

## 修复后的编辑规则

- 绿苹果增减必须输入正整数；设定允许 0。负数、小数、空值和溢出数字会显示错误并停止提交。
- 角色卡增减数量为 1–1000，设定数量为 0–100000；不再自动夹到边界值。
- 离线管理操作禁用，导航和搜索保留；权限处理不会重新启用本来应禁用的控件。
- 称号模板草稿有修改时，自动快照保留草稿；主动刷新提示先保存或重新打开页面。服务器回传与草稿一致时恢复为已同步状态。
- “卸下”在宽屏和窄屏使用同一行为与说明，无法通过该按钮清空拥有清单。
